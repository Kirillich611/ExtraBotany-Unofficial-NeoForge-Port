# ExtraBotany 1.9.3

Minecraft 1.21.1 / NeoForge 21.1.248 / Java 21. This is an unofficial port and a beta release.

## Changes

- Updated the addon for our Botania 457.1-SNAPSHOT port, including equipment, mana and relic capabilities, networking, HUD integration, and mixins.
- Updated flower state persistence, synchronization, and redstone behavior for the new Botania API.
- Regenerated 201 recipes and verified the resulting recipe data.
- Verified textures for Gaia Spirit Ingots and the Pleiades maid outfit.
- Updated the pairing with Botania's fixes for mana-pool rendering and the held Lexica Botania with shaders enabled.
- Added client and console-server launch scripts to the published source project.

## Requirements

Install our Botania 457.1-SNAPSHOT port, Patchouli and Curios for NeoForge 1.21.1. Use Java 21. Install the runtime JAR only; sources JARs and source ZIPs are development downloads.

## Validation

Both mods built successfully. ExtraBotany PMD and Spotless checks passed. All nine GameTests passed, including decoding 201 recipes and assembling 108 crafting recipes. A copied 188-mod profile loaded and rendered the mana pool, held lexicon, Gaia Spirit Ingot and maid outfit, with and without the tested shaders.

A full playthrough, complete boss fight, EMI and KubeJS integration have not been verified.
